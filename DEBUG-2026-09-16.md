## 1. Hvad er implementeret

En ny `action`-type i `tags.conf`. Hele resten af linjen er kommandoen (den
køres via `/bin/sh -c` løsrevet, når tagget lægges på). Nu også med af-kommando:

```
04B1B2B3FFFF  action  lamp on || lamp off
04B1B2B30002  action  ~/bin/party.sh on || ~/bin/party.sh off
```

- tag på → venstre side (on), køres i `watch::bind_one`
- tag af → højre side (off), køres i `watch::stop_active` (nyt `watch_action_stop`) —
  kun hvis af-delen findes; ellers "kan ikke stoppes automatisk"
- kommandoer startes via `launcher::run_detached` (dobbelt fork + setsid, stdio → /dev/null)
- action-tags stoppes **ikke** automatisk som Steam-spil (som lutris/heroic)

## 5. Format-noter

- Delimiteren `" || "` (med mellemrum) kan ikke indgå i en kommando — wrap i et
  script ved behov.
- `nfc write` skriver kun on-kommandoen (taggets navn) som NDEF — off er kun
  konfig-siden.
- `nfc start action 'on || off'` kører kun on-delen (ingen løft-hændelse).

## 6. emu-type (emulator-spil, med automatisk stop)

Format i `tags.conf`:

```
04B1B2B3AAAA  emu  dolphin -e ~/roms/MarioKartWii.iso
```

- tag på → kommandoen køres via `run_detached`, som nu **returnerer pid** for
  procesgruppens leder (grandchild gør `setsid`)
- tag af / skift / watch-stop → `launcher::stop_child(pid)` sender SIGTERM til
  hele procesgruppen (-pid) og eskalerer til SIGKILL efter ~5 s
- `nfc add emu '<kommando>'` / `nfc start emu '<kommando>'`; `nfc list`/`read`
  viser kommandoen; menupunkt 4 = "Bind nyt tag til et emulator-spil"
