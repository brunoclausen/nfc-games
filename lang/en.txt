help_text<<<
nfc — ACR122U NFC tags and Steam games

Usage:
  nfc --help
  nfc -h
  nfc version
  nfc                         interactive menu
  nfc menu                    interactive menu
  nfc <command> [arguments]

Tags and games:
  nfc games                   auto-scan Steam games and shortcuts
  nfc watch                   ready=green; tag on=yellow+2 beeps+start; tag off=1 beep+stop+green; stop=red
  nfc restart                 restart watch (systemd or pid)
  nfc genstart                same as nfc restart
  nfc start <game|appid>      start via Steam (games + emu shortcuts)
  nfc start                   read tag and start bound game
  nfc stop [game|appid]       stop running game
  nfc lock                    show which game is locked/running
  nfc add <game|appid>        find game, read tag, bind and write name
  nfc add action '<on> || <off>' bind a tag to shell actions (off runs when the tag is lifted)
  nfc start action <command>  run a shell action now (no tag needed)
  nfc add emu '<command>'      bind a tag to an emulator game (stopped when the tag is lifted)
  nfc start emu <command>      start an emulator game now (no tag needed)
  nfc lutris                  list Lutris games (wine/native, not Steam)
  nfc emu                     list emulator games from ~/Emulation/roms
  nfc write                   write game name onto the tag (so the phone is not empty)
  nfc read                    read tag (UID + bound game + NDEF)
  nfc list                    show saved tags (tags.conf)
  nfc remove <game|uid>       remove saved tag
  nfc remove                  read tag and remove it if saved
  nfc tag backup [file]       dump all tag pages to a .hex (default: ~/.config/nfc-games/tag-backups/<UID>-<time>.hex)
  nfc tag restore <file>      write tag pages back from a .hex

Language:
  nfc lang                    list languages and the active one
  nfc lang <code>             switch language and save it
  nfc sprog                   same as nfc lang

Reader:
  nfc farver                  test red/green/yellow LED + beep
  nfc led green|red|yellow|off
  nfc beep [ms]               beep (default 200)
  nfc firmware                show ACR122U firmware
  nfc udev                    show udev rule for ACR122U
  nfc udev install            install udev rule (pkexec)
  nfc install                 AppImage: ~/Applications, menu, autostart, udev

Help:
  nfc --help, nfc -h          this text
  nfc menu                    interactive menu (numbered)
  nfc help                    show HELP.md in the active language
  nfc version                 print version

Files:
  ~/.config/nfc-games/tags.conf  saved tags
  ~/.config/nfc-games/nfc.conf   selected language

Example:
  nfc games
  nfc add "BloodRayne 2"
  nfc watch
  nfc lang de
  nfc restart

winusb_text<<<
Windows does not use udev. The ACR122U needs the WinUSB driver, or nfc cannot open the reader.

Zadig is inside nfc.exe. Run:  nfc udev install

1. Run nfc udev install. Zadig is unpacked and opened. Or download it from https://zadig.akeo.ie/
2. Plug the reader in. Options → List All Devices
3. Select ACR122U or CCID USB Reader (USB 072f:2200)
4. Driver: WinUSB → Replace Driver
5. Unplug the reader and plug it back in

Tags are stored in %APPDATA%\nfc-games\tags.conf
Steam games start with steam://. Tag off stops the game process.
Emulator and action tags run through cmd.exe /c.
Hooks can read %NFC_ID% and %NFC_NAME%.
