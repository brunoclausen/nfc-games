help_text<<<
nfc — ACR122U NFC-brikker og Steam-spill

Bruk:
  nfc --help
  nfc -h
  nfc version
  nfc                         interaktiv meny
  nfc menu                    interaktiv meny
  nfc <kommando> [argumenter]

Brikker og spill:
  nfc games                   skann Steam-spill og snarveier
  nfc watch                   klar=grønn; brikke på=gul+2 pip+start; brikke av=1 pip+stopp+grønn; stopp=rød
  nfc restart                 start watch på nytt (systemd eller pid)
  nfc genstart                samme som nfc restart
  nfc start <spill|appid>     start via Steam
  nfc start                   les brikke og start bundet spill
  nfc stop [spill|appid]      stopp spill
  nfc lock                    vis låst/kjørende spill
  nfc add <spill|appid>       finn spill, les brikke, bind og skriv navn
  nfc write                   skriv spillnavn på brikken (så telefonen ikke viser tom)
  nfc read                    les brikke (UID + spill + NDEF)
  nfc list                    lagrede brikker
  nfc remove <spill|uid>      fjern brikke
  nfc remove                  les brikke og fjern

Språk:
  nfc lang                    list språk
  nfc lang <kode>             bytt språk og lagre
  nfc sprog                   samme som nfc lang

Leser:
  nfc farver                  test rød/grønn/gul LED + pip
  nfc led green|red|yellow|off
  nfc beep [ms]               pip (standard 200)
  nfc firmware                ACR122U-firmware
  nfc udev                    vis udev-regel
  nfc udev install            installer udev-regel (pkexec)
  nfc install                 AppImage: ~/Applications, meny, autostart, udev

Hjelp:
  nfc --help, nfc -h          denne teksten
  nfc menu                    interaktiv meny
  nfc help                    HELP.md på aktivt språk
  nfc version                 versjonsnummer
