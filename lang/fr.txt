help_text<<<
nfc — Tags NFC ACR122U et jeux Steam

Utilisation :
  nfc --help
  nfc -h
  nfc version
  nfc                         menu interactif
  nfc menu                    menu interactif
  nfc <commande> [arguments]

Tags et jeux :
  nfc games                   scanner les jeux Steam et raccourcis
  nfc watch                   prêt=vert ; tag posé=jaune+2 bips+lancer ; tag retiré=1 bip+stop+vert ; stop=rouge
  nfc restart                 redémarrer watch (systemd ou pid)
  nfc genstart                identique à nfc restart
  nfc start <jeu|appid>       lancer via Steam
  nfc start                   lire le tag et lancer le jeu lié
  nfc stop [jeu|appid]        arrêter le jeu
  nfc lock                    afficher le jeu verrouillé/en cours
  nfc add <jeu|appid>         trouver le jeu, lire le tag, lier et écrire le nom
  nfc add action '<marche> || <arrêt>' lier un tag à des actions shell (arrêt exécuté au retrait)
  nfc start action <commande> exécuter une action shell maintenant (sans tag)
  nfc add emu '<commande>'      lier un tag à un jeu d'émulateur (arrêté au retrait du tag)
  nfc start emu <commande>      lancer un jeu d'émulateur maintenant (sans tag)
  nfc lutris                  lister les jeux Lutris (wine/natif, pas Steam)
  nfc emu                     lister les jeux d'émulateur depuis ~/Emulation/roms
  nfc write                   écrire le nom du jeu sur le tag (le téléphone n'est plus vide)
  nfc read                    lire le tag (UID + jeu + NDEF)
  nfc list                    tags enregistrés
  nfc remove <jeu|uid>        retirer un tag
  nfc remove                  lire le tag et le retirer

Langue :
  nfc lang                    lister les langues
  nfc lang <code>             changer de langue et enregistrer
  nfc sprog                   identique à nfc lang

Lecteur :
  nfc farver                  tester LED rouge/vert/jaune + bip
  nfc led green|red|yellow|off
  nfc beep [ms]               bip (défaut 200)
  nfc firmware                firmware ACR122U
  nfc udev                    afficher la règle udev
  nfc udev install            installer la règle udev (pkexec)
  nfc install                 AppImage : ~/Applications, menu, démarrage, udev

Aide :
  nfc --help, nfc -h          ce texte
  nfc menu                    menu interactif
  nfc help                    HELP.md dans la langue active
  nfc version                 numéro de version
