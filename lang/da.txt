nfc — ACR122U NFC-tags og Steam-spil

Brug:
  nfc --help
  nfc -h
  nfc version
  nfc                         interaktiv menu
  nfc menu                    interaktiv menu
  nfc <kommando> [argumenter]

Tags og spil:
  nfc games                   auto-scan Steam-spil og shortcuts
  nfc watch                   klar=grøn; tag på=gul+2 beep+start; tag af=1 beep+stop+grøn; stop=rød
  nfc restart                 genstart watch (systemd eller pid)
  nfc genstart                samme som nfc restart
  nfc start <spil|appid>      start via Steam (spil + emu-genveje)
  nfc start                   læs tag og start bundet spil
  nfc stop [spil|appid]       stop kørende spil
  nfc lock                    vis hvilket spil der er låst/kører
nfc add <spil|appid>      find spil, læs tag, bind og skriv navn
  nfc add action '<på> || <af>' bind et tag til skal-handlinger (af kører når tagget løftes)
  nfc start action <kommando>  kør en skal-handling nu (intet tag nødvendigt)
  nfc add emu '<kommando>'      bind et tag til et emulator-spil (stoppes når tagget løftes)
  nfc start emu <kommando>      start et emulator-spil nu (intet tag nødvendigt)
  nfc lutris                  vis Lutris-spil (wine/native, ikke Steam)
  nfc emu                     vis emulator-spil fra ~/Emulation/roms
  nfc write                   skriv spilnavn på tagget (så telefonen ikke viser tom)
  nfc read                    læs tag (UID + bundet spil + NDEF)
  nfc list                    vis gemte tags (tags.conf)
  nfc remove <spil|uid>       fjern gemt tag
  nfc remove                  læs tag og fjern det hvis det er gemt
  nfc tag backup [fil]        backup alle sider til .hex (default: ~/.config/nfc-games/tag-backups/<UID>-<tid>.hex)
  nfc tag restore <fil>       gendan sider fra .hex på et tag

Sprog:
  nfc sprog                   vis sprog og hvilket der er aktivt
  nfc sprog <kode>            skift sprog og gem det
  nfc lang                    samme som nfc sprog

Læser:
  nfc farver                  test rød/grøn/gul LED + beep
  nfc led green|red|yellow|off
  nfc beep [ms]               bip (standard 200)
  nfc firmware                vis ACR122U-firmware
  nfc udev                    vis udev-regel til ACR122U
  nfc udev install            installér udev-regel (pkexec)
  nfc install                 AppImage: ~/Applications, menu, autostart, udev

Hjælp:
  nfc --help, nfc -h          denne tekst
  nfc menu                    interaktiv menu (tal-valg)
  nfc help                    vis HELP.md på aktivt sprog
  nfc version                 vis versionsnummer

Filer:
  ~/.config/nfc-games/tags.conf  gemte tags
  ~/.config/nfc-games/nfc.conf   valgt sprog

Eksempel:
  nfc games
  nfc add "BloodRayne 2"
  nfc watch
  nfc sprog de
  nfc restart

winusb_text<<<
Windows bruger ikke udev. ACR122U skal have WinUSB-driveren, ellers kan nfc ikke åbne læseren.

Zadig ligger inde i nfc.exe. Kør:  nfc udev install

1. Kør nfc udev install. Zadig pakkes ud og åbnes. Ellers hent den fra https://zadig.akeo.ie/
2. Sæt læseren i. Options → List All Devices
3. Vælg ACR122U eller CCID USB Reader (USB 072f:2200)
4. Driver: WinUSB → Replace Driver
5. Tag stikket ud og sæt det i igen

Tags gemmes i %APPDATA%\nfc-games\tags.conf
Steam-spil startes via steam://. Tag-løft stopper spillets proces.
Emulator- og handlings-tags kører via cmd.exe /c.
Hooks kan læse %NFC_ID% og %NFC_NAME%.
