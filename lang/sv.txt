help_text<<<
nfc — ACR122U NFC-taggar och Steam-spel

Användning:
  nfc --help
  nfc -h
  nfc version
  nfc                         interaktiv meny
  nfc menu                    interaktiv meny
  nfc <kommando> [argument]

Taggar och spel:
  nfc games                   skanna Steam-spel och genvägar
  nfc watch                   redo=grön; tagg på=gul+2 pip+start; tagg av=1 pip+stopp+grön; stopp=röd
  nfc restart                 starta om watch (systemd eller pid)
  nfc genstart                samma som nfc restart
  nfc start <spel|appid>      starta via Steam
  nfc start                   läs tagg och starta bundet spel
  nfc stop [spel|appid]       stoppa spel
  nfc lock                    visa låst/körande spel
  nfc add <spel|appid>        hitta spel, läs tagg, bind och skriv namn
  nfc add action '<på> || <av>' bind ett tagg till skalkommandon (av körs när taggen lyfts)
  nfc start action <kommando> kör en skalkommando nu (ingen tagg krävs)
  nfc add emu '<kommando>'      bind ett tagg till ett emulatorspel (stoppas när taggen lyfts)
  nfc start emu <kommando>      starta ett emulatorspel nu (ingen tagg krävs)
  nfc lutris                  visa Lutris-spel (wine/native, inte Steam)
  nfc emu                     visa emulatorspel från ~/Emulation/roms
  nfc write                   skriv spelnamn på taggen (så telefonen inte är tom)
  nfc read                    läs tagg (UID + spel + NDEF)
  nfc list                    sparade taggar
  nfc remove <spel|uid>       ta bort tagg
  nfc remove                  läs tagg och ta bort

Språk:
  nfc lang                    lista språk
  nfc lang <kod>              byt språk och spara
  nfc sprog                   samma som nfc lang

Läsare:
  nfc farver                  testa röd/grön/gul LED + pip
  nfc led green|red|yellow|off
  nfc beep [ms]               pip (standard 200)
  nfc firmware                ACR122U-firmware
  nfc udev                    visa udev-regel
  nfc udev install            installera udev-regel (pkexec)
  nfc install                 AppImage: ~/Applications, meny, autostart, udev

Hjälp:
  nfc --help, nfc -h          denna text
  nfc menu                    interaktiv meny
  nfc help                    HELP.md på aktivt språk
  nfc version                 versionsnummer
