help_text<<<
nfc — ACR122U-NFC-Tags und Steam-Spiele

Verwendung:
  nfc --help
  nfc -h
  nfc version
  nfc                         interaktives Menü
  nfc menu                    interaktives Menü
  nfc <befehl> [argumente]

Tags und Spiele:
  nfc games                   Steam-Spiele und Shortcuts scannen
  nfc watch                   bereit=grün; Tag auf=gelb+2 Pieps+Start; Tag ab=1 Pieps+Stop+grün; Stop=rot
  nfc restart                 Watch neu starten (systemd oder pid)
  nfc genstart                wie nfc restart
  nfc start <spiel|appid>     über Steam starten
  nfc start                   Tag lesen und gebundenes Spiel starten
  nfc stop [spiel|appid]      laufendes Spiel beenden
  nfc lock                    gesperrtes/laufendes Spiel anzeigen
  nfc add <spiel|appid>       Spiel finden, Tag lesen, binden und Namen schreiben
  nfc write                   Spielname auf das Tag schreiben (Telefon nicht leer)
  nfc read                    Tag lesen (UID + Spiel + NDEF)
  nfc list                    gespeicherte Tags
  nfc remove <spiel|uid>      Tag entfernen
  nfc remove                  Tag lesen und entfernen

Sprache:
  nfc lang                    Sprachen auflisten
  nfc lang <code>             Sprache wechseln und speichern
  nfc sprog                   wie nfc lang

Leser:
  nfc farver                  LED rot/grün/gelb + Piep testen
  nfc led green|red|yellow|off
  nfc beep [ms]               Piep (Standard 200)
  nfc firmware                ACR122U-Firmware
  nfc udev                    udev-Regel anzeigen
  nfc udev install            udev-Regel installieren (pkexec)
  nfc install                 AppImage: ~/Applications, Menü, Autostart, udev

Hilfe:
  nfc --help, nfc -h          dieser Text
  nfc menu                    interaktives Menü
  nfc help                    HELP.md in der aktiven Sprache
  nfc version                 Versionsnummer

Dateien:
  ~/.config/nfc-games/tags.conf  gespeicherte Tags
  ~/.config/nfc-games/nfc.conf   gewählte Sprache
